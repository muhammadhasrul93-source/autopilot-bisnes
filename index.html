Saya tak pandai coding. Boleh ikut?

Boleh. Ebook ini ditulis untuk orang bukan teknikal. Bab-bab awal tak perlukan coding langsung. Untuk automasi lanjutan, anda cuma salin prompt dan Claude yang menulis kod untuk anda.

Perlu bayar Claude ke?

Untuk chat asas, pelan percuma Claude boleh digunakan. Untuk automasi (Claude Code, Claude in Chrome, scheduled tasks) anda perlukan pelan berbayar, bermula daripada Claude Pro (USD20 sebulan) setakat November 2026. Ebook ini menerangkan pelan mana yang sesuai.

Saya guna Windows / MacBook. Boleh?

Boleh. Setiap langkah setup ada gambar untuk kedua-duanya.

Saya guna iPhone. Masih berguna?

Ya. Hanya Bab 6 (kawal telefon untuk autopost) memerlukan telefon Android. Bab lain (kandungan, penjadual rasmi, iklan, lead, playbook) tidak bergantung pada jenis telefon.

Selepas bayaran berjaya, anda akan dibawa ke halaman muat turun. Fail PDF boleh dibaca di handphone, tablet dan komputer.
